# Общие соглашения Avito Реклама API

## Пагинация и фильтры

Все list-методы (рекламодатели, договоры, кампании, группы, креативы) используют единый формат:

```json
{
  "filter": { /* специфичные для сущности фильтры */ },
  "limit": 20,
  "page": 1
}
```

| Поле | Тип | Ограничения | Default |
|---|---|---|---|
| filter | object | Обязательное; может быть `{}` — тогда фильтрация не применяется | – |
| limit  | integer | 1–100 | 20 |
| page   | integer | ≥ 1 | 1 |

В ответе всегда есть `total` (общее количество записей по фильтру) и массив сущностей. Для перебора всех страниц увеличивай `page` пока возвращаемый массив не опустеет, или пока `page * limit ≥ total`.

## Деньги и бонусы

- Все денежные значения — **целые числа в рублях с НДС**
- Минимальная сумма перевода — 1 ₽ / 1 бонус
- Поля `balance`, `bonusBalance`, `spend`, `spendBonus`, `budget`, `price`, `amount` — всегда целые

## Даты и периоды

- Формат даты — `YYYY-MM-DD` (например, `2025-01-31`)
- Временные метки в статистике (`timestamp`) — ISO 8601 с дневной гранулярностью (`2025-01-01T00:00:00Z`)
- Максимальный период между `dateFrom` и `dateTo` в статистике — **100 дней**

## Заголовки ответа

| Заголовок | Описание |
|---|---|
| `Api-Point-Balance` | Остаток API-баллов после выполнения запроса. У каждого метода своя стоимость в баллах (см. `x-cost` в OpenAPI). |

## Ошибки

Все ошибки возвращаются с JSON-телом одинаковой схемы:

```json
{
  "code": "string",
  "message": "string"
}
```

| HTTP | Когда |
|---|---|
| 400 | Невалидное тело: `amount < 1`, пустые обязательные поля, неверный формат дат, период статистики > 100 дней |
| 401 | Access token отсутствует, просрочен или невалиден |
| 403 | Токен не имеет прав на `accountID` в path |
| 404 | Аккаунт/сущность не найдены в контексте доступов текущего токена |
| 429 | Превышен лимит запросов. Используй retry с экспоненциальным backoff |
| 500 | Внутренняя ошибка сервера |
| 503 | Сервис временно недоступен |

## ID-плейсхолдер `{accountID}` в скриптах

`scripts/cli.py` подставит `{accountID}` в path автоматически из `AVITO_ADS_ACCOUNT_ID` в `.env`. Удобно копировать примеры из доков без редактирования.

Если хочешь обратиться к чужому accountID — подставь его в path вручную (но токен должен иметь права на этот accountID, иначе 403).

## Песочница vs Prod

См. `sandbox.md`. Главное правило: **начинай с sandbox**, переходи на prod когда поток запросов отлажен. Иначе быстро сожжёшь API-баллы на тестах.
